# Diese Library: HoymilesWiFi

- Diese Library dient zur Anbindung von Hoymiles Wechselrichtern mit eingebauter DTU und direkter Netzwerk/WLAN Anbindung, an die Software IP-Symcon. Sie stellt die notwendigen Module und Funktionen bereit, um diese Geräte in IP-Symcon zu integrieren und zu steuern.
- Die Library ist so konzipiert, dass sie leicht erweiterbar ist, um fehlende Abschnitte bei der Auswertung von Hoymiles-Paketen, welche per Protobuf angesprochen werden, zu ergänzen.
